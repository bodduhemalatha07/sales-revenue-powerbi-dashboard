# sales-revenue-powerbi-dashboard
Power BI dashboard for analyzing sales performance, return analysis, and product performance using interactive data visualizations.
This project presents an interactive Power BI dashboard designed to analyze sales performance, product performance, revenue trends, and returned products.
Dashboard Sections
1. Sales Overview
Provides an overview of overall sales and revenue performance.
Helps analyze sales trends and key business metrics.
2. Return Analysis
Analyzes returned products and return trends.
Helps identify products or categories with higher return activity.
3. Product Performance
Compares product-level performance.
Helps identify products contributing to overall sales and revenue.
